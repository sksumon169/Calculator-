# SK Calculator ULTIMATE 4.0

Developed by Sumon Rajbongshi.

## Included
- Standard expression calculator with brackets, %, history
- Scientific functions: sin/cos/tan, sqrt, square/cube, ln, log10
- Fraction arithmetic
- Percentage, discount, profit/loss, simple/compound interest
- EMI, loan breakdown, savings, SIP/investment, salary, VAT/GST
- Ratio, average/CGPA, age, date difference, date add/subtract, time difference
- Tip/split, fuel cost, electricity bill, speed-distance-time, work, mixture, HCF/LCM
- Number base converter
- Length, area, volume, weight, temperature, speed, pressure, data converters
- BMI and BMR
- Kirana/Taraju multi-product billing with quantity/weight, discount and optional purchase cost/profit
- Currency converter with live online rates from open.er-api.com, cached locally for offline conversion
- INTERNET permission is included. All calculator logic remains offline-capable.

## Build
Open this project in AndroidIDE. Sync Gradle, then Build > Assemble Debug.

## Important
This package is source code. This environment does not have an Android SDK configured, so an APK was not compiled here. Live currency requires internet only when updating rates; cached rates continue to work offline.
